Local LLMs on Android — BrokeAI

Local LLM Android

A lightweight installation script and WebUI designed to run Large Language Models locally on Android smartphones, featuring optimized modern AI engines like LiteRT and Wikipedia REST APIs accessible via a chat-like interface and system resource monitor. Runs on Android via Termux and exposes local OpenAI API endpoints for integration with other applications, such as Home Assistant (via the llama.cpp integration), AnythingLLM and any other agentic platform that supports the OpenAI API. The project is currently under development and will be released soon.
